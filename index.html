Setup & sync (one-time)
  1. Upload index.html to your repo. It works right away, saving on each device.
  2. To sync across phones: at console.firebase.google.com → New project → Build → Realtime Database → Create (test mode).
  3. Project settings → add a Web app → copy the firebaseConfig object.
  4. Paste it into FIREBASE_CONFIG near the top of the script in index.html, commit. Now every phone that opens the site shares the same plan — Ashley just opens the link.
